# City of Mirrors — The world of Lalon

A bilingual courtyard for exploring Lalon’s songs, philosophy, living performances, and source-linked scholarship.

**Visit: https://rubayatkhan.github.io/lalon/**

This repository contains the public static website. GitHub Pages publishes the root of the `main` branch. No installation or build is required; `index.html`, `style.css`, `app.js`, and `data/archive.json` are the application.

The collection includes 465 song records, 235 Bengali texts, twelve newly prepared English readings, and forty source records including six doctoral dissertations. Translation, attribution, and source-access limitations are stated in the website.

## Credits and reuse

See [CREDITS.md](CREDITS.md) for source attribution, text licensing, historic portrait credit, and font licenses. The site is an independent project named for Arshinagar and is not affiliated with the publishers or editors of Carol Salomon’s separately cited book.

The supplied song PDF, modern scholarly PDFs, private research files, and working notes are excluded. The PDF reading room can open a visitor-selected local file in the browser without uploading it.

## Hosting

This is a static site with relative asset paths and hash-based navigation. It can be hosted on GitHub Pages, another static host, or a custom domain. No server-side services, secrets, analytics, or paid hosting dependencies are required.

To preview this checkout locally: `python3 -m http.server 4174` and open `http://localhost:4174/`.
